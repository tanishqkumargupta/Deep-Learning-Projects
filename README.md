# Deep Learning Projects Collection

This repository contains implementations of different Artificial Neural Network (ANN) and Convolutional Neural Network (CNN) models for classification problems.

## Projects Included

### 1. Credit Card Fraud Detection using ANN

Objective:
Detect fraudulent financial transactions using Artificial Neural Networks.

Concepts:
- Data preprocessing
- Feature scaling
- Artificial Neural Networks
- Binary classification
- Model evaluation


### 2. Cancer Classification using CNN

Objective:
Classify medical images using Convolutional Neural Networks.

Concepts:
- Image preprocessing
- CNN architecture
- Pooling layers
- Dense layers
- Classification


### 3. Face Recognition using LFW Dataset

Objective:
Build a CNN model for face recognition using the Labeled Faces in the Wild dataset.

Concepts:
- Computer Vision
- CNN feature extraction
- Image classification


### 4. CIFAR-10 Classification

Objective:
Classify images from CIFAR-10 dataset into multiple categories.

Concepts:
- Deep CNN
- Multi-class classification
- Model training
- Evaluation


## Technologies Used

- Python
- TensorFlow/Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook
