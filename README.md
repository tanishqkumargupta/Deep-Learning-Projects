# Deep Learning Projects Collection

This repository contains a collection of Machine Learning, Deep Learning, Reinforcement Learning, and Deployment projects developed using Python and popular AI frameworks. The projects demonstrate practical implementations of classification, computer vision, recommendation systems, reinforcement learning, and end-to-end machine learning pipelines.

---

## Projects Included

### 1. Adult Census Income Classification

**Objective:**  
Predict whether an individual's annual income exceeds \$50K using an Artificial Neural Network (ANN).

**Concepts:**
- Data preprocessing
- Feature scaling
- Artificial Neural Networks (ANN)
- Binary classification
- Model evaluation

**Technologies:** TensorFlow, Keras, Pandas, NumPy, Scikit-learn

---

### 2. Brain Cancer Detection using MRI Images

**Objective:**  
Classify MRI brain images for tumor detection using Convolutional Neural Networks (CNN).

**Concepts:**
- Medical image preprocessing
- CNN architecture
- Image classification
- Performance evaluation

**Technologies:** TensorFlow, Keras, OpenCV, NumPy

---

### 3. Face Recognition using LFW Dataset

**Objective:**  
Build a CNN model for face recognition using the Labeled Faces in the Wild (LFW) dataset.

**Concepts:**
- Computer Vision
- CNN feature extraction
- Face classification
- Image preprocessing

**Technologies:** TensorFlow, OpenCV, Scikit-learn

---

### 4. CIFAR-10 Image Classification

**Objective:**  
Classify images from the CIFAR-10 dataset into ten different object categories.

**Concepts:**
- Deep CNN
- Multi-class classification
- Image preprocessing
- Model evaluation

**Technologies:** TensorFlow, Keras, NumPy, Matplotlib

---

### 5. Cart-Pole RL Agent Training

**Objective:**  
Train a Deep Q-Network (DQN) agent to balance a pole on a moving cart using reinforcement learning.

**Concepts:**
- Reinforcement Learning
- Deep Q-Network (DQN)
- Policy learning
- Agent evaluation

**Technologies:** Stable-Baselines3, Gymnasium, PyTorch

---

### 6. Lunar Lander RL Agent Training

**Objective:**  
Train a DQN agent to successfully land a spacecraft in the LunarLander environment.

**Concepts:**
- Reinforcement Learning
- Deep Q-Network (DQN)
- Reward optimization
- Environment interaction

**Technologies:** Stable-Baselines3, Gymnasium, PyTorch

---

### 7. Movie Recommendation System

**Objective:**  
Build a content-based movie recommendation system that suggests similar movies based on textual metadata.

**Concepts:**
- TF-IDF Vectorization
- Cosine Similarity
- Recommendation Systems
- Feature Engineering

**Technologies:** Pandas, NumPy, Scikit-learn

---

### 8. End-to-End Student Performance Prediction

**Objective:**  
Develop a complete machine learning pipeline for predicting student mathematics scores and deploy it using Flask.

**Concepts:**
- Data preprocessing
- Machine Learning Pipeline
- Model serialization
- Flask deployment

**Technologies:** Scikit-learn, Flask, Pandas, NumPy
